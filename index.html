About Personal Expense Tracker

A complete frontend web application built to track daily income and expenses, monitor monthly budget usage, visualize spending reports, and export records to CSV—powered by browser Local Storage.

Core Concepts & Features

  • HTML Forms & Validation: Clean inputs with inline error messages for empty fields, invalid numbers, and dates.
  • CSS Flexbox & Grid: Adaptive responsive layout with Light & Dark theme variables.
  • JavaScript Objects & Arrays: Structured transaction objects managed with filter(), map(), reduce(), and sort().
  • DOM Manipulation & Events: Live search, multi-filter, instant KPI updates, visual progress bars, and toast alerts.
  • Local Storage & CSV Export: Persistent browser storage plus one-click spreadsheet export.
